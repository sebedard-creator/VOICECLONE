# Configuration locale

Les fichiers de ce dossier peuvent contenir des identifiants Google et des chemins propres a ce PC. Ils ne doivent jamais etre ajoutes a Git.

Pour une nouvelle installation, copie `settings.example.json` vers `settings.json`, puis renseigne les valeurs locales requises.

Ne publie jamais les fichiers suivants:

- `oauth_client.json`
- `oauth_token.json`
- `service_account.json`
- `settings.json`
- `voice_bank.json`
